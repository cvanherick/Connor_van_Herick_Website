CS61C Project 2

CS61Classify in RISC-V Assembly

I implemented the low-level routines behind a small neural-network classifier in RISC-V assembly, including matrix multiplication, vector operations, activation functions, binary matrix file I/O, and the top-level inference pipeline.

The code is private due to academic integrity. I can share or discuss the implementation directly with recruiters or interviewers where appropriate.
RISC-V Assembly implementations of math, I/O, control flow, and error handling.
ML Pipeline Matrix operations and ReLU/argmax inference behavior for classification.
Tested Unit and coverage tests for individual routines and chained execution.

What I Built

CS61Classify connects several low-level routines into a working classifier. I implemented assembly functions for absolute value, ReLU, argmax, dot product, matrix multiplication, matrix read/write, and the classify pipeline that ties model weights and input matrices into an end-to-end prediction.

The project required careful register discipline, stack management, pointer arithmetic, heap allocation, file handling, and defensive error paths in a setting where small mistakes can corrupt program state silently.

Engineering Focus

Assembly Routines

  • dot, matmul, relu, and argmax
  • Binary matrix read/write helpers
  • Classification orchestration
  • Error handling for invalid dimensions and file operations

What It Demonstrates

  • Low-level debugging under strict calling conventions
  • Understanding ML computation beneath Python libraries
  • Modular testing of assembly routines
  • End-to-end reasoning across memory, files, and math

Why It Matters

This project connects machine learning with computer systems at the lowest practical level. It shows that I can reason about ML workloads not just as library calls, but as memory layout, arithmetic kernels, calling conventions, and execution flow.

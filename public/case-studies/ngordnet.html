CS61B Project

Ngordnet Language Explorer

I built a Java language-data application that combines Google NGram frequency data with WordNet graph relationships to answer historical usage and hyponym queries through web handlers.

The code is private due to academic integrity. I can share or discuss the implementation directly with recruiters or interviewers where appropriate.
JavaObject-oriented data structures and query handlers.
GraphsWordNet synset and hyponym traversal over directed relationships.
DataTime-series aggregation over NGram frequency datasets.

What I Built

The project loads word-frequency data into reusable time-series structures, parses WordNet synsets and hyponym relationships into a graph, and exposes query handlers that combine both sources to return useful language information.

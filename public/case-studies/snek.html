CS61C Project 1

Snek Game Engine in C

I implemented the core logic for a terminal Snake game in C, including board parsing, snake state management, food handling, collision logic, file input/output, unit tests, and integration tests across a range of board layouts.

The code is private due to academic integrity. I can share or discuss the implementation directly with recruiters or interviewers where appropriate.
C Manual memory management, structs, pointers, and file I/O.
21 Boards Integration tests covering simple, multi-snake, huge, wide, and edge-case maps.
Robustness Unit tests plus Valgrind-ready checks for memory correctness.

What I Built

The project centers on a game engine that reads board files, constructs in-memory game state, advances snakes through each turn, resolves food and wall interactions, and writes the resulting board state back out.

The main challenge was making state updates precise in a low-level language: every snake segment, tail movement, collision case, and file boundary needed to be handled without leaks or invalid memory access.

Engineering Focus

Core Systems

  • Board parsing and serialization
  • Snake head/tail tracking
  • Food consumption and growth behavior
  • Wall and self-collision handling

Quality Bar

  • Unit tests for game-state helpers
  • File-based integration tests against reference outputs
  • Nonexistent-input handling
  • Memory checks through Valgrind workflow support

Why It Matters

Snek is a compact systems project, but it exercises the same habits needed in larger codebases: define clear state representations, make ownership explicit, test edge cases, and debug behavior from concrete inputs and outputs.

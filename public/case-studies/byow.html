Build Your Own World

I built a tile-based Java game engine with procedural world generation, player movement, enemies, line-of-sight behavior, theme switching, multilingual menus, and persistent save/load functionality.

Run Locally

The download above is a runnable JAR built from my actual Java Project 3 source. After downloading: 

java -jar byow-demo.jar

The cleaned codebase also includes a recruiter README and Makefile. From the Project 3 source directory: 

make compile
make run
make jar

Main controls: N starts a new game, enter a seed followed by S, move with WASD, toggle line-of-sight with N, change themes with T, and save/quit with :Q.

What I Built

Game Systems

  • Seeded room and hallway generation
  • Avatar movement and collision behavior
  • Enemy pathfinding toward the player
  • Line-of-sight rendering mode
  • Theme switching and English/French menus

Engineering Focus

  • Stateful Java architecture
  • Deterministic generation for reproducibility
  • Serializable save/load game state
  • Autograder-style input simulation for tests

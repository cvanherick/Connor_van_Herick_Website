CS61B Project

Build Your Own World

I built a tile-based Java game engine with procedural world generation, player movement, enemies, line-of-sight behavior, and persistent save/load functionality.

The code is private due to academic integrity. I can share or discuss the implementation directly with recruiters or interviewers where appropriate.
JavaObject-oriented game systems split across world, entities, menu, and movement modules.
GenerationSeeded procedural worlds with rooms, paths, and deterministic replay behavior.
PersistenceSave/load support for interactive state and repeatable game sessions.

What I Built

The project turns a random seed into a playable world, renders it with a tile engine, accepts movement input, tracks game state, and restores saved sessions. I also added game-specific systems such as enemies and line-of-sight behavior.
